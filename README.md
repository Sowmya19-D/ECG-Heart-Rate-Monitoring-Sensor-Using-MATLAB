# ECG-Heart-Rate-Monitoring-Sensor-Using-MATLAB
An ECG Heart Rate Monitoring System using MATLAB to analyze electrocardiogram (ECG) signals and calculate heart rate in beats per minute (BPM). The project uses an Arduino UNO and AD8232 ECG sensor to acquire ECG signals, while MATLAB performs signal filtering, R-peak detection, and heart rate calculation for real-time heart rate monitoring.
